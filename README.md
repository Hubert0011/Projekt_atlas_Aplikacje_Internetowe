# Atlas Polskich Lasów


Projekt z przedmiotu Aplikacje internetowe. Aplikacja to responsywny, interaktywny atlas flory i fauny polskich lasów, zbudowany zgodnie z nowoczesnymi standardami webowymi (Semantic HTML5, CSS3, Vanilla JS) bez użycia zewnętrznych bibliotek i frameworków.

## Github pages
Projekt jest opublikowany i dostępny pod adresem: 
https://hubert0011.github.io/Projekt_atlas_Aplikacje_Internetowe/index.html

## Funckjonalności
- **Katalog Flory i Fauny**: Baza kilkudziesięci gatunków roślin/grzybów i kilkunastu gatunków zwierząt (dane oddzielone od logiki w `data.js`).
- **Okienka typu modal**: Dynamicznie generowane wyskakujące okienka z rozszerzonym opisem i dodatkowymi zdjęciami (np. całe drzewo + pęd).
- **Filtrowanie zawartości**: Filtrowanie kart kategorii za pomocą JS bez przeładowywania strony.
- **Dark Mode / Light Mode**: Zaimplementowany motyw jasny i ciemny z zapamiętywaniem wyboru użytkownika w localStorage.
- **Responsywność (RWD)**: Dostosowanie do urządzeń mobilnych z wykorzystaniem CSS Grid, Flexbox oraz nawigacją typu hamburger menu.
- **Walidacja formularza**: Walidacja formularza kontaktowego obsługiwana przez JavaScript.

## Technologie
- **HTML5**: Semantyka i dostępność (atrybuty `aria`, `alt`).
- **CSS3**: Zmienne CSS (`:root`), Grid, Flexbox, Media Queries, animacje i płynne przejścia.
- **JavaScript (ES6+)**: Tablice obiektów, manipulacja DOM, Event Listenery, LocalStorage.
